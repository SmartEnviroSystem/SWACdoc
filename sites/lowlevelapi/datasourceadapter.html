DataSourceAdapter

DataSourceAdapter finds measurement records in unknown JSON structures, flattens nested values and creates datasets that can be used by SWAC components.

Adapt nested JSON data

Edit the example JSON and run the adaptation. The result shows the detected record path, numeric attributes, time attribute and normalized datasets.

Edit the JSON and adapt the data.

Use DataSourceAdapter

import DataSourceAdapter from '/SWAC/swac/DataSourceAdapter.js';

let result = DataSourceAdapter.adaptCapsule({
    data: sourceJson,
    fromName: 'water_measurements'
});

if (result.usable)
    console.log(result.sets);
else
    console.warn(result.reason);

Result structure

The result contains sets, rowPath, numericAttrs, dateAttrs, timeAttr, attribute labels and warnings. The usable value indicates whether the source could be adapted.
