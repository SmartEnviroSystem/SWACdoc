AIDataSourceAdapter

AIDataSourceAdapter creates normalized SWAC datasets from JSON data. It first uses deterministic adaptation and can use a configured service when deterministic adaptation is not sufficient.

Adapt JSON data

The following example uses deterministic adaptation. The result has the same structure as a service based adaptation and can therefore be used by Present, Charts and other SWAC components.



            
import AIDataSourceAdapter from '/SWAC/swac/AIDataSourceAdapter.js';

let result = await AIDataSourceAdapter.adaptCapsule({
    data: sourceJson,
    fromName: 'external_measurements'
}, {mode: 'auto'});

if (result.usable)
    console.log(result.sets);
else
    console.warn(result.warnings);


            
Adaptation modes

            
Use deterministic to disable service requests. Use auto to request the configured service only when the deterministic result needs improvement. Use ai to require service based adaptation.


            
Service configuration

            
Keep access keys on the server. The browser configuration only contains the address of a server side proxy.

            
window.SWAC_AI_CONFIG = {
    proxyEndpoint: '/api/ai/adapt',
    model: 'configured-model'
};

            
The proxy receives the normalized request, retrieves its access key from protected configuration and forwards the request to the selected service.
