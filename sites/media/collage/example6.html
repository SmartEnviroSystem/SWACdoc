Example 6: Keogram from a file

Same as example 5, but from a static file, so no database is needed. The file contains the stripes of every 20th image of the night of 15.06.2026 (about one every 3 minutes).
The images between 01:40 and 02:00 were left out to show how gaps in the data are drawn: they stay empty and are shown hatched.
The image shown in large is loaded from the server of the LMU, so an internet connection is needed for it.
