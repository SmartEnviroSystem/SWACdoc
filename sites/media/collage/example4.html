Example 4: Try options

Change the values below and press Apply to see their effect on the collage. Fields left empty use the default value. Under CONFIGURATION you find the code for exactly this collage, ready to copy into your own page.

Datasource

Display

The timeline shows one image after the other. A keogram puts a stripe of every image side by side to show the whole time at once. Automatic chooses the timeline for normal images.

How many images the timeline loads and shows at once. Default: 20.

Navigation

How far the jump buttons next to the images go. Only for images with timestamp. Default: 3600 (1 hour).
Not used here, the images of this datasource have no timestamp.

How many images the jump buttons skip. Only for images without timestamp. Default: 10.
Not used here, the images of this datasource have a timestamp.

Playback

How long each image is shown when playing with the play button or the space key. Smaller is faster. Default: 500 (half a second).

Reset
CONFIGURATION

Code for the collage above. Only changed options are listed, all others use their default value.
