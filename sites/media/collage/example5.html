Example 5: Keogram from SmartData

The SmartDataPorter stores a stripe of every image: keogram_column_png is the middle column (north-south), keogram_line_png the middle row (east-west). The option keogramAttr names the attribute with the stripe. The collage draws the stripes side by side by their timestamp, so the keogram shows how the sky changed over time. Gaps in the data are shown hatched.
The image of the selected dataset is shown in large, here from the server of the LMU (option pathAttr), so an internet connection is needed.
This example needs the database smartmonitoring_helios and SmartDataHELIOS like example 3. If nothing appears after starting the database, reload the page with clearstates=true.

The interval draws only one image every 20 seconds, 30 seconds and so on (option keogramInterval). Click, arrow keys and playback then use only these images. The speed changes the time each image is shown while playing (option playInterval). With high speeds the loading of the images from the LMU can be slower than the chosen speed.
