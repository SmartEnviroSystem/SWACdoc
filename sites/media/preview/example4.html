Example 4: Live data from SmartData

Loads the 1200 sky images from the collection unimunic_asi of SmartDataHELIOS. SmartData evaluates the filters of the navigation, so only the shown media are transferred, even if there are thousands of media.
The datasets contain the path of the image on the server of the LMU in the attribute origin_url, so the option pathAttr is set. An internet connection is needed.
The number of media is requested with countonly, the first and last timestamp with size=1.
This example needs the database smartmonitoring_helios and SmartDataHELIOS on the server like in the SmartMonitoringDeveloper environment. If the images do not appear after starting the database, reload the page with clearstates=true.

VIEW-Requestor 

<div id="mediapreview_example4" swa="Mediapreview FROM /SmartDataHELIOS/smartdata/records/unimunic_asi WHERE storage=smartmonitoring AND order=ts,ASC AND size=24 AND includes=id,ts,mimetype,origin_url"></div>
