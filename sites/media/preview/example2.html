Example 2: Navigate through pages

Sky images of the all sky imager of the LMU Munich from 15.06.2026, one image per minute.
The buttons below the media show the first, previous, next and last page. The media have a timestamp, so the pages are loaded by the timestamp (filter ts,gt / ts,lt) and the page shows the time range of its media.
Below the pages a timepoint can be chosen, the buttons jump one hour back or forward and a click on the time axis shows the media of that time. The play button shows the following pages automatically, the list sets how long each page is shown.
A click on an image opens the big view with the Collage component. There the images can be navigated one by one and played like a video. After closing, the page with the last shown image is shown.
A static file ignores the filters of the navigation, so the component filters the delivered datasets itself and shows pageSize media.
The images are loaded from the server of the LMU, so an internet connection is needed.
