Example 5: Select several datasets

With the option multiple the datasets are selected with checkboxes in a dropdown. Only attributes that the collections of all selected datasets have are offered:

  • Weather station and Weather station 2: only temperature (both have it)
  • Weather station 2 alone: temperature, pressure and wind_speed
  • Weather station and Power meter: no common attribute and no common time column

getSelection() and the event deliver all selected datasets in sets. Each entry has a filter (option filterAttribute, default oo_id) for collections several datasets share.
The URL holds the ids separated by commas, so the selection can be shared (oo_id=1,3&attribute=temperature).
