Example 4: React on the selection

Dataselect fires the event swac_REQUESTOR_ID_dataselect_changed whenever the dataset, the attribute, the time attribute or the period changed. The event delivers what changed and the new selection. getSelection() delivers the same selection at any time.
The dataset given in the URL parameter oo_id is preselected (oo_id=1, oo_id=2).
