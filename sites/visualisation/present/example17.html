Example 17: Switch between datasources

Every component can get a list of additional datasources with the option datasources. Each entry has a readable name and a fromName, optionally with fromWheres. The source from the FROM clause is added automatically. Name it by adding an entry with the same fromName, as done here with "Station north".

With showSidebar: true the sidebar (cog icon in the upper right corner) offers the datasources for choice. Choosing one removes the shown datasets and loads the datasets of the choosen source. The plugins of the component are loaded again, so results for the old data (like the columns of the DatasetAnalysis plugin) are removed.

Switch by code

Pages can switch the datasource without the sidebar, for example from their own select box. The component fires swac_present_example17_datasource_switched when the new data is loaded.

let comp = document.querySelector('#present_example17').swac_comp;
comp.getDatasources();                  // [{name, fromName, fromWheres}, ...]
comp.switchDatasource('Station south'); // returns a Promise
