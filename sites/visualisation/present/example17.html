Example 17: TableActions Plugin

TableActions adds configurable icon buttons to each table row. Each action defines an id prefix, a UIkit icon, a title for tooltips and accessibility, and an onClick function. Optional visible(dataset) and disabled(dataset) functions control each button. Here, Edit appears only for even-numbered ids; the checkbox enables it. Call view.getPlugin('TableActions').swac_comp.refresh() after external state changes.

The function receives the complete dataset, for example show(dataset). Access fields directly with dataset.id, or use dataset.set_json to get a JSON string without internal SWAC references for sending or storing the data.
