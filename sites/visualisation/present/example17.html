Example 17: TableActions Plugin

TableActions adds icon-only buttons to every dataset row. Configure an actions array in the plugin entry. Each action has an id prefix, a UIkit icon name, a title and an onClick function reference. The title is used as a native tooltip and accessible name. Clicking a button passes the dataset id to its function, preserving its original type. Pass onClick: show, not onClick: show(). Functions do not need to be attached to window when they are in scope of the configuration.

Button ids use prefix_datasetId, for example show_1. Collisions (including multiple tables or data sources) receive a numeric suffix. SWAC normally generates ids for datasets without one; if no id reaches the plugin, it uses a row number instead. New rows loaded later also receive buttons. The action column is added only when the plugin is active and actions are configured.

Alternatively, use SWAC's separate plugin options variable window['TableActions_present_example17_options'] = {actions: [...]}. Its actions override those in the plugin entry. This plugin targets table_for_all_datasets and compatible table templates.

Click an action button to see its dataset id.
