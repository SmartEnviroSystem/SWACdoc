Example 42: Raster with separate width and height

Each dataset is ment for a rectangle around its location (raster display). The website admin sets areaShape: 'rect' and the size of the raster with areaSize. Here the width and height are different: areaSize: [3000, 2000] draws cells of 3 km in east-west direction (longitude) and 2 km in north-south direction (latitude). The measuring point (marker) is in the middle of each cell. A single number like areaSize: 3000 still draws squares (see example 39). Colors come from the Datadescription component, with the ColorSelect plugin the user can switch between irradiance and cloud cover.
