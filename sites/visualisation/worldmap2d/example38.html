Example 38: Color markers by a combination of multiple attributes

With the option colorCombination the color is calculated from multiple attribute values. Supported modes are max / min (color of the attribute with the highest / lowest level, e.g. the worst pollutant), avg / weighted (average level, colored by the description of targetAttr) and custom (own function). In this example irradiance and cloud cover are combined into a photovoltaic suitability. The user can still choose a single attribute with the ColorSelect plugin.
