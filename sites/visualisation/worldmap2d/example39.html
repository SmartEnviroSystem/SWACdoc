Example 39: Display raster data as areas around the locations

Sometimes data is given for a concrete location, but ment for an area around this location, e.g. satellite data where each value describes a raster cell of 3 x 3 km. With the option areaShape (rect or circle) an area is drawn around every location, areaSize sets its size in meters. The areas are colored like the markers by the ColorSelect plugin (option colorAttr, or areaColorAttr for a different attribute). The colors are taken from the Datadescription component.
With the ColorSelect plugin the user can choose another attribute, markers and areas are recolored.
