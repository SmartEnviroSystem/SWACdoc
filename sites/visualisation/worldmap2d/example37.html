Example 37: Let the user choose the attribute for coloring

The ColorSelect plugin adds a button to the map. There the user can choose which attribute determines the color of the markers (and areas). A legend for the chosen attribute is shown. The entry Default returns to the coloring configured by the administrator.
Other scripts can use setColorAttr(attr) on the map component and listen to the event swac_REQUESTOR_ID_colorattr_changed.
