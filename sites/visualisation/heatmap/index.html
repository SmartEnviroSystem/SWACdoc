Example: Colouring table values

Heatmap uses Present to build the table and Datadescription to provide the legend colours.

With autoLegend enabled, Heatmap calculates the minimum, median and maximum for each visible numeric column. The thresholds are (minimum + median) / 2, (maximum + median) / 2 and maximum. Values below the first threshold are green, values below the second are yellow, and the remaining values up to and including the maximum are red. Colours can be edited in the legend.

CONFIGURATION

datadescription identifies the legend element by its ID without #. autoLegend generates the thresholds from the loaded data. attrVisibility hides columns using the existing Present option. formatAttributeBorders disables the legend's attribute borders in this example.

DATASOURCE

This example reuses the data from Datadescription example 3.
